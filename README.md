# Тестовое задание AviaTX: разбор status report

Разобрать выгрузку из системы техобслуживания самолётов в строгий JSON.
Условие — в [TASK_RU.md](TASK_RU.md). **Времени: 60 минут.**

## Как работать

1. **Форкните** этот репозиторий к себе (кнопка «Fork» вверху справа).

2. Включите Actions в форке: вкладка **Actions** → кнопка
   **«I understand my workflows, go ahead and enable them»**.
   В форках они по умолчанию выключены, без этого проверки не запустятся.

   В исходном репозитории проверки намеренно не запускаются — там лежит
   заготовка без решения. Запускаться они начнут в вашем форке.

3. Склонируйте форк и поставьте зависимости:

   ```bash
   git clone https://github.com/<ваш-логин>/aviatx_interview.git
   cd aviatx_interview
   pip install -r requirements.txt
   ```

4. Допишите функцию `parse_workbook()` в [parse.py](parse.py). Всё остальное
   в файле уже готово — сборка итогового объекта, сортировки, вывод.

5. Проверяйте себя локально сколько угодно:

   ```bash
   python parse.py data/status_report.xlsx > result.json
   python validate.py result.json     # структура ответа
   python selfcheck.py result.json    # сверка значений
   ```

6. Когда готово — запушьте в свой форк:

   ```bash
   git add parse.py
   git commit -m "Решение"
   git push
   ```

   Те же три проверки прогонятся в Actions. Пришлите ссылку на форк.

## Что в репозитории

| Файл | Что это |
|---|---|
| `TASK_RU.md` | Условие задачи и контракт итогового JSON |
| `data/status_report.xlsx` | Исходная выгрузка, 100 тасков |
| `parse.py` | Заготовка решения — дописать `parse_workbook()` |
| `result.schema.json` | Контракт в виде JSON Schema, читать не обязательно |
| `validate.py` | Проверка структуры ответа |
| `selfcheck.py` | Сверка значений с эталоном |
| `expected_hashes.json` | Хеши эталонных значений — служебный файл для `selfcheck.py` |

`selfcheck.py` знает только хеши, поэтому скажет «колонка `cw_hours` разошлась
в строках 41 и 73», но не покажет, какое значение ожидалось. Разбираться,
почему разошлось, — часть задачи.

## Правила

Гуглить, читать документацию и подсматривать синтаксис — можно и нужно.
Нельзя одно: отдать задачу целиком чат-боту и запушить его ответ.

Если что-то в условии непонятно — спрашивайте, это не штрафуется.
